# glia

Небольшая библиотека для создания LLM-агентов. Каждый вызов модели и
инструмента и каждое изменение состояния — обычный объект, который можно
записать в лог, сохранить и воспроизвести. Цикл агента помещается в один файл.

Название — от глиальных клеток, которые поддерживают и связывают нейроны.

## Зачем

Агентные фреймворки обычно прячут поток управления, поэтому их тяжело
отлаживать. В glia цикл агента маленький и читается целиком. Инструменты,
структурированный вывод, стриминг, параллельный запуск инструментов, сжатие
контекста, чекпойнты, guardrails, подтверждение действий человеком, сабагенты и
эвалы в виде тестов подключаются отдельно.

## Установка

```bash
pip install glia-agents               # ядро — без зависимостей
pip install "glia-agents[anthropic]"  # + провайдер Claude
```

Пакет называется `glia-agents`; импорт всегда `import glia`.

## За 30 секунд

```python
import asyncio
from glia import Agent, tool
from glia.providers import ClaudeLLM

@tool
async def get_weather(city: str) -> str:
    """Узнать текущую погоду в городе."""
    return {"Paris": "18°C, облачно"}.get(city, "неизвестно")

async def main():
    agent = Agent(ClaudeLLM(), tools=[get_weather], system="Отвечай кратко.")
    result = await agent.run("Какая погода в Париже?")
    print(result.output)   # ответ
    print(result.usage)    # во сколько обошлось

asyncio.run(main())
```

Нет ключа API? Все примеры работают офлайн с детерминированным провайдером
`EchoLLM` — тот же код, без обращения к сети.
